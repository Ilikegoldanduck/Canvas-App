# Canvas App
First time using C++ :p
This is sorta just a canvas app where you can draw/write anything I guess. 
I built this just to get used to C++ and just try out a new language. Tbh, it is kinda fun. Just not something I'm very good at lol.

Install Instructions:
 - Install .zip file from Releases
 - Unzip the .zip file
 - Run .exe

How to run:
 - 1. Line draw
   - <img width="710" height="494" alt="image" src="https://github.com/user-attachments/assets/5dfdaffd-01f5-4193-85d1-7dd137d645b5" />
   - Line tool create lines.
   - ctrl + click to end the line.
 - 2. Free write
   - <img width="700" height="525" alt="image" src="https://github.com/user-attachments/assets/b96a9527-24b5-43e2-ab25-20b7ff7e0049" />
   - Hold left mouse button to draw
   - Release left mouse button to end the line
 - 3. Box draw
   - <img width="701" height="532" alt="image" src="https://github.com/user-attachments/assets/f3ad68cc-6377-417d-8eec-3f959d623497" />
   - Hold left mouse button to change its size
   - Release to confirm the end of the line
 - 4. Erasing (Only works on lines)
   - <img width="705" height="497" alt="image" src="https://github.com/user-attachments/assets/8270fe21-09a1-453c-b999-df983c4e1f26" />
   - Hold left mouse button and move around to erase line segments
   - Release to stop erasing
 - You can use the GUI on the top right or number keys (1, 2, 3 and 4) to change tools
 - Delete the canvasSave file to refresh your save
 - Arrow keys to move your camera around
 - No zooming at the moment

 Third Party Licenses:
  - SDL3 was used for window management, input handling and rendering.
  - SDL3_TTF was used in text rendering.
  - IBMPlexMono_Regular font was used as the font when rendering text.
